# Calculadora básica con TDD

Proyecto de práctica para aprender **Desarrollo Guiado por Pruebas (TDD)** utilizando JavaScript, Node.js y Vitest.

## Tecnologías

- JavaScript
- Node.js
- Vitest
- Git y GitHub

## Estructura del proyecto

```text
calculadora-basica-tdd/
├── src/
│   └── calc.js
├── test/
│   └── calc.test.js
├── .gitignore
├── package.json
├── package-lock.json
└── README.md
```

## Instalación

Clona el repositorio e instala las dependencias:

```bash
npm install
```

## Ejecutar las pruebas

Para ejecutar las pruebas una vez:

```bash
npm test
```

Para ejecutarlas en modo observación:

```bash
npm run test:watch
```

## Objetivo

Practicar el ciclo TDD:

1. **RED:** escribir una prueba que falle.
2. **GREEN:** implementar el código necesario para superar la prueba.
3. **REFACTOR:** mejorar el código manteniendo las pruebas correctas.
